# Crawl Logs

This directory contains logs from successful crawl runs.

## Log Format

Logs are automatically generated by Scrapy and stored with timestamps.

## Viewing Logs

Logs are saved in the `web_crawler/.scrapy/` directory and also output to console during crawl execution.

### Example Log Output

## Log Files

- `crawl_YYYY-MM-DD.log` - Daily crawl logs with timestamps
- Logs are automatically rotated and archived
